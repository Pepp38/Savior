# Savior
Savior est un moteur d’autosave ultra-léger pour formulaires web. Il récupère automatiquement les brouillons, même après un rafraîchissement, une erreur ou un crash du navigateur.  Pensé pour être intégré en quelques secondes, Savior garde vos utilisateurs en sécurité : ils ne perdent plus jamais ce qu’ils écrivent.
